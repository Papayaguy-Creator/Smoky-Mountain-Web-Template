🚀 QUICK START GUIDE:

STEP 1: CUSTOMIZE YOUR CONTENT
1. Open smokies-booking-template.html in any text editor (Notepad, VS Code, etc.)
2. Replace ALL placeholders with your business information:
   - [Your Business Name] - Replace with your actual business name
   - [Service 1], [Service 2], [Service 3] - Replace with your actual services
   - [Price] - Add your actual pricing
   - [Your Email] - Replace with your contact email
   - [Your Phone] - Add your phone number
   - [Your Address] - Add your business address
   - [YOUR_EMAIL_HERE] - Update email addresses in the form handlers

STEP 2: HOST YOUR WEBSITE (FREE OPTIONS)
Option A - Netlify (Recommended - FREE):
1. Go to netlify.com and create a free account
2. Drag and drop your HTML file into the Netlify dashboard
3. Get your live website URL instantly!

Option B - GitHub Pages (FREE):
1. Create a GitHub account (free)
2. Create a new repository
3. Upload your HTML file
4. Enable GitHub Pages in settings

Option C - Paid Hosting (For Custom Domain):
- Namecheap: Domains from $8.98/year, hosting $2.99/month
- Bluehost: Starting at $3.95/month
- GoDaddy: Various hosting plans available

STEP 3: SET UP THE CHATBOT
The chatbot is already built-in and ready to go! It includes intelligent responses for:
- Service inquiries

STEP 4: CUSTOMIZE COLORS & STYLING (OPTIONAL)
You can easily customize the colors by editing the CSS styles:

3. Test the chatbot by clicking the chat icon
4. Check on mobile devices for responsiveness
